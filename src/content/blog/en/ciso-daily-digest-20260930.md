## Citrix NetScaler: Critical Zero-Days Escalate as Spectre-v2 BTR Undermines CPU Mitigations

Two critical **Citrix NetScaler ADC and Gateway** flaws continue exploitation as a new **Spectre-v2 variant** defeats decade-old CPU defenses. **CVE-2026-88771** (improper input validation) and **CVE-2026-88772** (DTLS memory overflow), both **CVSS 9.5**, require no authentication in default configurations. Citrix patches **14.1-73.37+** and **13.1-64.23+** are mandatory; no workarounds exist. In a separate but equally critical thread, academics from **VUSec and Scuola Superiore Sant'Anna** disclosed **Branch Target Reuse (BTR)**, a new Spectre v2 variant that exploits Just-In-Time (JIT) code in web browsers, language runtimes and the Linux kernel. **BTR bypasses Training Solo and existing Spectre v2 mitigations** by leveraging stale indirect branch prediction entries that outlive self-modified code—proof-of-concept exploits on fully-patched Intel systems leak root password hashes within minutes. This intersection of zero-days (Citrix) and long-standing architectural vulnerabilities (CPU) defines the week's risk posture: active exploitation combined with fundamental CPU design flaws that vendors cannot easily patch.

## Active Threats This Week

📌 **Spectre-v2 BTR: New CPU Attack Leaks Linux Kernel Memory, Bypasses Existing Hardening**
Researchers unveiled **Branch Target Reuse (BTR)**, a practical **in-place Spectre-v2 attack** exploiting the interplay between self-modifying code (SMC) and indirect branch prediction in JIT engines. Unlike traditional Spectre-v2 attacks that hijack branch targets across different locations, BTR exploits "temporal" violations where the target stays the same but the underlying code changes—feasible in JIT engines. Two end-to-end exploits against the Linux kernel **cBPF JIT leak and recover the root password hash within minutes on fully-patched Intel systems with default protections enabled**. The attack undermines existing mitigations (Training Solo CVE-2024-28956 and CVE-2025-24495) and has no scope limitations for systems running kernel JIT engines. Linux kernel patches (CVE-2026-64507, CVE-2026-64508) were merged following responsible disclosure; GraalVM randomizes JIT code-cache locations; Mozilla is prioritizing site isolation over IBPB-based mitigations.
🔗 **Reference:** [The Hacker News](https://thehackernews.com/2026/09/new-spectre-v2-btr-attack-leaks-linux.html)

📌 **France's Tax Authority: 600,000+ Records Stolen Via Weak Credential Controls**
**France's DGFIP (tax administration)** disclosed a multi-month data theft affecting **~350,000 individuals and ~250,000 businesses** that went undetected for seven weeks. Attackers used **stolen staff passwords**—likely harvested by infostealers from personal devices—to compromise portals **PIGP** (email/HR) and **ADER** (government-network RIE access), then pivoted to **E-Contact**, the taxpayer messaging tool. The ANSSI audit reveals fundamental weaknesses: no session termination on password reset, unmonitored ADER access, missing multi-factor authentication, and no data-volume alerts despite **11 GB exfiltrated in three days**. A second route through **APEX** (partner portal for notaries and surveyors) exposed **~435,000 household land-registry records**. Infrastructure came from compromised **Education Ministry systems on the RIE network**, with no segregation protecting sensitive DGFIP applications. ANSSI's recommendations: revoke all active sessions on password reset, deploy MFA with hardware tokens, monitor all business applications in a SIEM, enforce quotas on data access, and block personal-device access to work resources.
🔗 **Reference:** [The Hacker News](https://thehackernews.com/2026/09/french-tax-data-theft-using-stolen.html)

📌 **Russia's Star Blizzard: 100+ Organizations Targeted With Fake Event Invites, RedFlick Backdoor**
**Microsoft** tracked **Star Blizzard** (Russia's FSB Center 18) deploying **13 larger phishing campaigns** in 2026, each with tens to hundreds of emails. Since March, the group uses hacked **WordPress and cPanel email accounts** instead of free services. The lure: invitations from **Chatham House, Atlantic Council** and other think tanks, often impersonating the target's organization. Victims receive **password-protected RAR/ZIP archives** (password in image) containing shortcut files disguised as PDFs. Opening the LNK file quietly runs commands fetching **MSI installers** that create three scheduled tasks—**Internet Quality Test Connection, Network Configuration Manager, System Health Monitor**—delivering **CosmicPulse**, a Python-based backdoor. The technique, codenamed **RedFlick**, escapes older ClickFix detection. Targeted lures included fake tax audits, water shutdown notices and international organization payment notices. A March campaign delivered the **DarkSword iPhone exploit kit** instead of Windows malware. Affected organizations span the U.S., U.K., Australia, and Ukraine; no confirmed compromises were disclosed, but Microsoft notifies targeted/compromised customers.
🔗 **Reference:** [The Hacker News](https://thehackernews.com/2026/09/russias-star-blizzard-targets-100.html)

📌 **JPCERT Weekly Report: 30 Vulnerabilities Across ServiceNow, Adobe, GitLab, Tomcat, Cisco and More**
**JPCERT/CC** issued a comprehensive weekly report covering **30 distinct vulnerability disclosures** from September 13-26. High-severity items include: **ServiceNow AI Platform** (multiple vulns), **Adobe products** (APSB26-151), **Unbound DNS** (CVE-2026-xxxx), **Apache Tomcat** (multiple), **Next.js ImageResponse RCE**, **Microsoft Edge**, **WordPress PHP RFI**, **Google Chrome**, **GitLab**, **Cisco Identity Services Engine CVE-2026-76460** (active exploitation), **Cisco Secure Email Gateway SQL injection**, **F5 BIG-IP Access Policy Manager buffer overflow** (active exploitation), and dozens of plugin/extension flaws. Of note: **Acronis Backup plugin for cPanel & WHM** privilege escalation already being exploited; **MikroTik RouterOS** combined-vulnerability chain (MikroTrick) tied to 2.6 million exposed devices globally. Patching windows are immediate for active-exploitation items.
🔗 **Reference:** [JPCERT/CC Weekly Report](https://www.jpcert.or.jp/wr/2026/wr260930.html)

📌 **OpenSSL: High-Severity DTLS Flaw Leaks Heap Memory Unencrypted**
**OpenSSL** released patches on **September 29** for **CVE-2026-84782**, a High-severity DTLS handshake flaw. When a large DTLS handshake message's send operation pauses midway, the resend timer can fire and replay an earlier message using the paused message's buffer position instead of restarting—wrongly labeled and carrying **leaked heap memory as unencrypted handshake data**. Fixed in **4.0.3, 3.6.5, 3.5.9, 3.4.8**; OpenSSL 3.0 fixes are premium-support-only (public support ended September 7). CVSS 8.2; Ubuntu 22.04/24.04 receive patches via libssl3 updates; reboot required. No active exploitation reported; WebRTC and encrypted-call setups are exposure vectors.
🔗 **Reference:** [The Hacker News](https://thehackernews.com/2026/09/openssl-fixes-high-severity-dtls-flaw.html)

📌 **C-Suite Phishing Campaign Steals Microsoft 365 Sessions and Deploys RMM Tools**
**ANY.RUN** researchers traced a **US-focused CSuite phishing campaign** across 351 sandbox analyses, **51% from the United States**. The operation combines two attack paths: credential-harvesting/device-code phishing to steal **Microsoft 365 access and active sessions**, and BAT/VBS droppers deploying legitimate RMM tools (**ScreenConnect, Action1**) for persistent remote access. Lures impersonate **Adobe, DocuSign, Zoom, Google Meet, Dropbox, Microsoft 365**. In one sandbox session, an Adobe-themed lure delivered a BAT file that escalated privileges and installed ScreenConnect. High-exposure sectors: **Technology, Manufacturing, Government, Consulting**. Broader impact: attackers gain control over both business accounts and employee devices simultaneously—mailbox takeover, financial fraud (invoice manipulation), persistent endpoint access, and internal spread all become possible from a single phishing click.
🔗 **Reference:** [The Hacker News](https://thehackernews.com/2026/09/us-focused-csuite-phishing-steals.html)

📌 **Lunex Stealer: MaaS Platform Expands with BYOVD Defense Evasion**
**Ontinue** expanded its analysis of **Lunex Stealer**, identifying **28 active command-and-control panels across 13 countries** operated by Russian-speaking developers. The platform's deployment via **ClickFix** fake CAPTCHAs targets Ukrainian-speaking users. Exploitation chains bypass **UAC** via CMSTPLUA and abuse a vulnerable **AMD Radeon driver (PDFWKRNL.sys, CVE-2023-20598)** to **escalate privileges and blind security monitoring processes while leaving them running**—a stealthy BYOVD tactic. Exfiltration covers credentials from **7 Chromium browsers, 9 cryptocurrency wallets**, and establishes persistence through a **Chrome Native Messaging Host**—a PowerShell script supporting **6 filesystem actions (list_drives, list_dir, read_file, write, download, run)**. Platform expansion from June to September indicates either single-operator growth or active MaaS resale; hosted panels in Russia, U.S., U.K., Netherlands, France, Germany, Turkey, Bangladesh suggest fragmented infrastructure.
🔗 **Reference:** [The Hacker News](https://thehackernews.com/2026/09/lunex-stealer-abuses-amd-driver-to.html)

📌 **Pentagon Personnel Database: Millions of Records Exposed**
**Bitdefender** reported a breach of the Pentagon's personnel database exposing **personal data of millions** of service members, civilian employees and contractors. Details remain limited; incident response ongoing.
🔗 **Reference:** [Bitdefender Security Blog](https://www.bitdefender.com/en-us/blog/hotforsecurity/pentagon-personnel-database-breach-personal-data-millions)

📌 **Citrix NetScaler CVE-2026-88772: Exploit Details Show Memory-Overflow Path to Shellcode**
**watchTowr** released proof-of-concept exploit details for **CVE-2026-88772**, demonstrating how the DTLS fragment-length parsing inconsistency leads to buffer overflow and control-flow hijacking. An attacker crafts malicious DTLS records where **fragment_length=1 but actual data is much larger**, bypassing the **35,840-byte scratch buffer** after 120 records accumulate **~174 KB**. The overflow can be weaponized using **mprotect()** to defeat NX protections and divert execution to arbitrary shellcode with **root privileges**. Combined with CVE-2026-88771, this creates a two-flaw exploitation chain with no authentication barrier.
🔗 **Reference:** [The Hacker News](https://thehackernews.com/2026/09/citrix-netscaler-cve-2026-88772-exploit.html)

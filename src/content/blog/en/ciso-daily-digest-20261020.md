## Zeabur再遭駭宣布年底停運，逾321萬筆環境變數遭讀取、8月憑證未完成輪替 - iThome

Zeabur 遭遇第二次駭客攻擊，運營團隊宣佈將於年底停運。事件導致逾 321 萬筆使用者的環境變數被竊取，安全風險極高。

根據報導， 이번 공격은 8월에 발행된 인증서가 갱신되지 않아 발생했으며, 공격자는 이를 이용해 민감한 환경 변수에 접근했습니다. Zeabur 表示 이번 해킹으로 인해 사용자의 중요한 데이터가 유출될 가능성이 있습니다.

廠商目前正在調查事件來源，並建議受影響的使用者立即輪替所有密鑰與憑證，以減緩潛在的安全風險。

### CISO Impact

- **Credential lifecycle governance —** Enforce strict certificate rotation policies and automate credential revocation to prevent prolonged access from expired or unrotated secrets, as demonstrated by the Zeabur incident where an incomplete August certificate replacement led to environment variable theft.
- **APT28 tradecraft escalation —** Monitor for reflective loader deployment and persistent SSH tunnel patterns attributed to APT28 (Swallowtail/HOOKEDGE), as the group combines credential theft, multi-technique access, and novel in-memory payload execution against high-value NATO infrastructure.
- **Merchant spyware risk assessment —**  Treat Apple Threat Notifications as high-confidence indicators of targeted mercenary spyware activity; deploy Lockdown Mode and forensic verification for at-risk personnel, especially ahead of election periods, as confirmed in the Pegasus case involving a Serbian university rector.

## Active Threats This Week

📌 **Russian APT28 Breaches NATO Naval Shipbuilder in NATO Country, Deploys New Reflective Loader**

Russian APT28 has been attributed to attacks targeting two member states of the North Atlantic Treaty Organization (NATO), including a naval shipbuilder and a manufacturer of military aircraft engines. The Symantec Threat Hunter Team, tracking the activity cluster under the moniker Swallowtail, involved the use of a backdoor called HOOKEDGE and a previously undocumented loader designed to decrypt and run an encrypted payload in memory using a cryptographic key supplied at runtime. During one attack against the naval shipbuilder, operators returned to a compromised host repeatedly over the course of a week in what appeared to be hands-on-keyboard activity, stealing credential material using two separate techniques, opening a persistent SSH tunnel into the organization's internal network and deploying a previously undocumented reflective loader.

📌 **Pegasus Spyware Infection Confirmed on Serbian University Rector's iPhone Days Before Election**

The iPhone of Vladan Đokić, rector of the University of Belgrade and a prominent supporter of Serbia's student protest movement, was infected with NSO Group's Pegasus spyware in 2026, the Citizen Lab said on October 19. The finding came six days before Serbia's October 25 snap parliamentary election. The infection used a zero-click exploit, meaning Đokić did not have to tap a link or open a file for it to work. The lab found the infection with high confidence, but its note provides no date within 2026, does not identify who was behind the attack, and notes that its investigation is ongoing.

📌 **Popular WordPress SEO Plugin Rank Math PRO Hijacked to Deliver Self-Restoring Backdoor**

Popular WordPress SEO Plugin Rank Math PRO Hijacked to Deliver Self-Restoring Backdoor. Copies of Rank Math PRO, the paid version of the Rank Math SEO plugin for WordPress, that were downloaded from rankmath.com or delivered as updates between 20:02 UTC on October 15 and 07:12 UTC on October 16 contained malware. Any site that installed and activated one of those copies should be treated as compromised. The malware can recreate its hidden backdoor whenever someone visits the site. Rank Math has removed the affected files and released a clean version, 3.0.124. Installing it replaces the plugin but does not remove files, administrator accounts, or scheduled tasks the malware may have placed elsewhere on the server. A copy of 3.0.123 obtained before 20:02 UTC on October 15 is outside the window. The notice sorts sites into cases: installed and activated during the window, treat as compromised; installed but never activated, delete plugin files, install 3.0.124, run a scan; downloaded but never installed or activated, nothing indicates compromise. Rank Math has emailed users and told anyone unsure to contact support. The notice applies only to the PRO plugin. The free plugin is not named. What is known about the malware comes from Rank Math’s notice; neither it nor Wordfence includes code analysis or attribution. Deleting suspicious files before stopping what recreates the backdoor may not resolve the problem. The attacker may have left PHP backdoor files in other plugins’ folders, in theme folders, and in the must-use plugins directory, created administrator accounts, added a fake WordPress core file, changed .htaccess so that .cache files run as PHP, and added scheduled tasks and SSH keys. Any password, database credential, API key, or other secret the site may have reached may have been exposed. Wordfence assigned CVE-2026-111862 and rates it 9.8 out of 10. Patchstack classifies it as a backdoor and says that because the attack was on Rank Math’s own systems, a rule is not possible for mitigation. Preferred recovery is a restore from a backup of the site and its database from before 20:02 UTC on October 15, run a security scan, change every password and credential, then install 3.0.124. Where no clean backup exists, manual cleanup in fixed order: delete entire rank-math-pro plugin folder, deactivating plugin alone is not sufficient, delete entries \_uf6qdn2hmm, t8krdk990phb, \_np5pvf754c from wp\_options, block outgoing connections to rank1cdn.com, then search for other changes in files, code, and accounts. Credentials are changed in every case even after restore. The cleanup ends with a security scan, wp core verify-checksums, and wp plugin verify-checksums --all. WordPress.org publishes none for this one. The clean 3.0.124 goes on last, downloaded by logging in at rankmath.com directly. Some customers may be unable to log in and may need to reset account password; Rank Math will never send login or download links by email. Rank Math, part of the Swedish hosting group group.one, has not said how the malicious files entered its system, how many customers received one, whether automatic updates delivered them, or what the hashes are. Its only statement about the future is that the team is taking steps to reduce risk. Registry records show the domain rank1cdn.com was registered at 19:31 UTC on October 14. This is at least the third time this year a premium WordPress plugin’s vendor-run update channel delivered backdoored builds. In April Nextend’s update system served a backdoored Smart Slider 3 Pro. In June ShapedPlugin’s Pro plugins were found backdoored; one package shipped clean was later tampered with under the same version number. Attackers also altered scripts served from Awesome Motive’s CDN in June and poisoned BdThemes’ API feed in August. Nothing links the attackers behind any of those incidents to this one.

📌 **ClickFix Attackers Exploit Siemens Software Center Flaw to Deploy Remote Access Trojan**

ClickFix Attackers Exploit Siemens Software Center Flaw to Deploy Remote Access Trojan. Siemens has addressed a DLL sideloading vulnerability impacting Siemens Software Center, tracked as CVE-2026-110936 (CVSS v4 score: 8.4). The high-severity vulnerability could allow an attacker to place a specially-crafted DLL in a directory the application searches, resulting in execution of malicious code with the same privileges as the affected service. The affected application loads dynamic-link libraries (DLLs) from an uncontrolled search path. This could allow an authenticated local attacker to place a specially crafted DLL in a directory that the application searches, leading to arbitrary code execution with the privileges of the affected application. The issue has been patched in version 4.0.9.8. Huntress Labs researcher Jose Oregon has been credited with discovering and reporting the shortcoming. Attackers have abused a genuine copy of Siemens Software Center with a valid signature and placed their own crafted DLL (archive.dll) next to it to trigger execution of malicious code. They chose this program as a carrier because it is signed and trusted, and because version 3.5.8.7 loaded helper files from its own folder without checking them. Specifically, threat actors have been found leveraging msiexec.exe to launch AllMyBasic.msi, which then executes SiemensSoftwareCenter.exe. The activity has been attributed to a ClickFix delivery platform called Romulus, used to deliver Legion Loader and other malware using DLL sideloading. According to Huntress, some campaigns have leveraged malicious ChatGPT Custom GPTs to direct victims to a fake URL responsible for serving a ClickFix lure, which when copied and executed by the victim, runs PowerShell code to drop an MSI installer that abuses DLL sideloading to ultimately deploy a remote access trojan. Siemens has shared indicators of compromise: 96.62.218.59 (payloading hosting and command-and-control), wizardexpensive.com (payloading hosting and command-and-control), 2.27.248.127 (distribution channel of AllMyBasic.msi). Organizations are advised to block the IP addresses and domains associated with the malicious activity and look for SiemensSoftwareCenter.exe running from AppData\\Local\\Programs and started by msiexec.exe. The issue has been patched in version 4.0.9.8.
